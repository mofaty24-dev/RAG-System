# RAG QA System

A Retrieval-Augmented Generation system that answers questions based on PDF documents.

## Features
- Semantic search using FAISS
- LLM-based answer generation
- Source grounding
- FastAPI backend

## Tech Stack
- Python
- FAISS
- Sentence Transformers
- TinyLlama
- FastAPI

## Run
uvicorn app:app --reload
